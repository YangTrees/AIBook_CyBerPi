# CyberPi（点点）32课动手互动流程全案
## 统一设计说明
1. **硬件基底**：全程仅使用 CyberPi 原生硬件（1.44寸彩屏、5颗RGB灯、光线传感器、三轴陀螺仪、麦克风/扬声器、五向摇杆+A/B按键、WiFi/蓝牙），零外接传感器、零接线、零扩展模块。
2. **IP设定**：套入云朵硅胶套的 CyberPi 统一称为「点点」，所有硬件反馈均以角色口吻输出，无技术术语，符合3-9岁儿童认知。
3. **交互原则**：孩子动手操作纸质/物理教具，点点负责声光画面反馈；操作动作限定为「插、摆、叠、倾斜、遮挡、按键」6类，低龄儿童可独立完成。
4. **结构统一**：每节课包含「核心知识点 + 点点硬件调用 + 配套物理教具 + 分步互动流程 + 知识点落点」5部分。

## 第一模块：信息基础（第1-4课）
### 第01课 小侦探找线索｜信息从哪里来
- **核心知识点**：AI通过传感器收集外界信息，就像人用眼睛耳朵观察世界
- **点点硬件调用**：光线传感器 + 彩屏 + 扬声器
- **配套教具**：线索卡片（树叶、脚印、花朵）、纸质侦探卡槽、放大镜卡纸
- **动手互动流程**：
  1. 孩子将点点放入侦探卡槽底座，手持放大镜卡纸，扮演AI小侦探。
  2. 依次把线索卡片插进卡槽，卡片刚好遮挡点点正面的光线传感器。
  3. 每插入一张，点点播放对应线索的提示音，屏幕同步显示线索特写画面。
  4. 三张线索全部收集完成后，屏幕自动拼出完整结论（如“是小兔子来过花园”），播放破案成功音效。
- **知识点落点**：传感器就是AI的眼睛和耳朵，收集到的线索越多，知道的信息就越全。

### 第02课 开关城的两兄弟｜二进制0与1
- **核心知识点**：计算机用“开/关”两种状态表达所有信息，这就是二进制
- **点点硬件调用**：5颗RGB灯 + A/B按键 + 彩屏
- **配套教具**：黑白双面大颗粒积木（黑=0、白=1）、二进制编码对照表卡片
- **动手互动流程**：
  1. 孩子对照编码表，用黑白积木在桌面摆出5位二进制组合。
  2. 用A键切换灯位、B键切换亮灭，把积木组合对应到点点的5颗RGB灯上（白=亮=1，黑=灭=0）。
  3. 拨动摇杆确认，点点屏幕显示该编码对应的字母/卡通图案，扬声器播报“解码成功！”。
  4. 更换不同积木组合，解锁更多图案，理解“开关组合能变出所有信息”。
- **知识点落点**：电脑里的文字、图片、声音，拆到底都是由“开和关”拼成的。

### 第03课 小邮差的密码信｜编码与加密
- **核心知识点**：按规则把普通信息换成暗号就是编码，反过来就是解码
- **点点硬件调用**：五向摇杆 + 彩屏 + 扬声器
- **配套教具**：密码对照表卡片、空白信纸卡纸
- **动手互动流程**：
  1. 孩子对照密码表，用摇杆在点点屏幕上输入想写的秘密文字。
  2. 点点自动将文字转换成符号密码，显示在屏幕上。
  3. 孩子把密码抄在信纸上，交换给家长；家长在点点上输入密码符号，点点还原出原文，播放“解密成功”音效。
- **知识点落点**：只有知道规则的人才能看懂密码，这就是信息加密的秘密。

### 第04课 仓库管理员机器人｜分类编码存储
- **核心知识点**：给物品编上号码，就能又快又准地找到它
- **点点硬件调用**：光线传感器 + 彩屏 + 扬声器
- **配套教具**：迷你物品卡片（文具、玩具、水果）、纸质仓库货架卡槽、编号贴纸
- **动手互动流程**：
  1. 孩子先给每张物品卡片贴上专属编号贴纸。
  2. 将物品卡片依次插进货架卡槽，每插一张遮挡一次光线传感器，点点屏幕自动记录编号和对应货架位置。
  3. 全部入库完成后，孩子用按键输入任意编号，点点立刻显示对应物品和存放位置，播放“找到啦！”。
- **知识点落点**：给数据编好号码存起来，机器人管理仓库就会又快又整齐。

## 第二模块：图像表示（第5-8课）
### 第05课 小方块拼出大世界｜像素构成
- **核心知识点**：所有图片都是由一个个小小的彩色方块（像素）组成的
- **点点硬件调用**：1.44寸彩屏 + 五向摇杆 + A/B按键
- **配套教具**：8×8纸质像素底板、彩色插粒
- **动手互动流程**：
  1. 孩子先用彩色插粒在纸质底板上拼出简单图案（如小太阳、点点头像）。
  2. 操作摇杆移动光标、B键切换颜色，在点点屏幕的8×8网格里，一格一格还原纸质图案。
  3. 填完后按摇杆确认，点点将像素图放大展示，播放“像素画完成！”的表扬音效。
- **知识点落点**：我们看到的电视、平板画面，拆开来全是密密麻麻的彩色小方块。

### 第06课 红绿蓝灯的合唱团｜RGB三原色
- **核心知识点**：红、绿、蓝三种光叠加，可以调出所有颜色
- **点点硬件调用**：全彩屏 + 顶部RGB灯
- **配套教具**：红、绿、蓝三片亚克力透光片
- **动手互动流程**：
  1. 点点屏幕全屏显示纯红色光，孩子直接用眼睛观察。
  2. 叠上绿色透光片，肉眼直观看到红光+绿光变成黄色；顶部RGB灯同步亮起黄光验证。
  3. 再叠蓝色透光片，观察三色叠加接近白色；单独更换组合，验证红+蓝=紫、绿+蓝=青。
- **知识点落点**：电脑屏幕只有红、绿、蓝三盏小灯，靠不同亮度搭配就能变出所有颜色。

### 第07课 行李箱装不下啦｜图像压缩
- **核心知识点**：去掉不重要的细节，图片文件就会变小，方便存放
- **点点硬件调用**：彩屏 + A/B按键
- **配套教具**：同款图案卡片（高清版/简化版各一张）、行李箱造型卡纸
- **动手互动流程**：
  1. 点点屏幕先显示高清版团团头像，细节丰富、占用空间大。
  2. 孩子把“行李箱卡纸”放在屏幕前，按A键触发“压缩”。
  3. 屏幕瞬间切换为简化像素版，图案细节变少但仍能认出团团，模拟“装进小行李箱”。
  4. 对比两张实物卡片，理解“压缩就是牺牲一点细节，节省空间”。
- **知识点落点**：图片压缩就像叠衣服，去掉多余空隙，就能装进更小的箱子。

### 第08课 雾气里的照片｜图像降噪
- **核心知识点**：模糊有噪点的图片，AI可以通过算法还原清晰
- **点点硬件调用**：彩屏 + 光线传感器 + 扬声器
- **配套教具**：磨砂透明卡、噪点贴纸
- **动手互动流程**：
  1. 点点屏幕显示一张布满噪点的模糊图片，像蒙了一层雾。
  2. 孩子把磨砂透明卡盖在屏幕上，模拟“降噪算法”，同时遮挡光线传感器触发识别。
  3. 屏幕瞬间切换为清晰原图，播放“变清楚啦！”的惊喜音效。
  4. 孩子可以贴上噪点贴纸重复操作，对比模糊与清晰的差异。
- **知识点落点**：AI能擦掉照片上的“噪点雾气”，让模糊的图片重新变清晰。

## 第三模块：算法入门（第9-12课）
### 第09课 红灯停绿灯行｜条件判断算法
- **核心知识点**：如果满足条件，就执行对应动作，是计算机的基础逻辑
- **点点硬件调用**：光线传感器 + RGB灯 + 彩屏
- **配套教具**：红/绿纸质指令牌、“如果…那么…”纸质卡槽板
- **动手互动流程**：
  1. 孩子先在卡槽板上拼出规则：如果举红牌→亮红灯停；如果举绿牌→亮绿灯行。
  2. 把红色指令牌放在点点光敏处，点点立刻亮起红灯，屏幕显示“停”字。
  3. 换成绿色指令牌，点点亮起绿灯，屏幕显示“行”字。
  4. 可自定义规则（如举红牌播放音效），验证条件判断逻辑。
- **知识点落点**：算法就是提前定好规则，满足什么条件，就做什么事情。

### 第10课 会数数的刷牙机器人｜循环算法
- **核心知识点**：重复做同一件事叫循环，能自动完成重复工作
- **点点硬件调用**：RGB灯 + 扬声器 + 按键
- **配套教具**：纸质牙齿模型、刷牙打卡条
- **动手互动流程**：
  1. 孩子用按键设定刷牙次数（如10次），按A键开始循环。
  2. 点点的RGB灯按节奏左右闪烁，模拟牙刷来回移动，同时同步报数“1、2、3…”。
  3. 数到设定次数自动停下，播放“刷牙完成！”的表扬音效。
  4. 孩子在打卡条上记录次数，理解“循环就是一遍一遍重复做”。
- **知识点落点**：循环能让机器人自动做重复的事，不用每次都下新指令。

### 第11课 做披萨的流水线｜顺序算法
- **核心知识点**：按正确步骤一步步做，就能准确完成复杂任务
- **点点硬件调用**：光线传感器 + 彩屏 + 扬声器
- **配套教具**：4张披萨工序卡（揉面、涂酱、放料、烘烤）、纸质流水线卡槽
- **动手互动流程**：
  1. 孩子把4张工序卡按顺序排进流水线卡槽。
  2. 每推进一张卡片遮挡一次光敏，点点屏幕就播放对应工序的动画。
  3. 四张按顺序全部推进后，屏幕出现完整披萨，播放“披萨出炉啦！”。
  4. 故意排错顺序（如先烘烤再涂酱），点点显示“披萨做坏啦”，体现顺序的重要性。
- **知识点落点**：顺序算法就是按正确的步骤，一步一步把事情做完。

### 第12课 找bug的小修理工｜程序调试
- **核心知识点**：程序出错很正常，找到错误并改正就叫调试
- **点点硬件调用**：彩屏 + 按键 + 扬声器
- **配套教具**：带错误的流水线卡片、bug贴纸、修理工小徽章
- **动手互动流程**：
  1. 点点运行一段错误的披萨程序，屏幕显示制作失败，播放“出错啦”音效。
  2. 孩子观察工序卡片，找出顺序错误的步骤，贴上bug贴纸标记。
  3. 按下B键触发修正，重新运行程序，披萨成功出炉，点亮修理工徽章动画。
  4. 多次试错练习，理解“找bug、改bug”就是调试。
- **知识点落点**：程序出错不可怕，找到错误并改正，就是厉害的小修理工。

## 第四模块：数据排序分类（第13-14课）
### 第13课 袜子大整理｜数据分类
- **核心知识点**：把有相同特征的东西归在一起，就是分类
- **点点硬件调用**：光线传感器 + 彩屏 + RGB灯
- **配套教具**：不同颜色/图案的袜子卡片、两个纸质收纳盒卡槽
- **动手互动流程**：
  1. 孩子把袜子卡片一张一张插进卡槽，遮挡光敏触发识别。
  2. 点点自动识别袜子的颜色特征，屏幕提示“分到左边/右边收纳盒”。
  3. 孩子按照提示，把卡片放进对应的实物收纳盒。
  4. 全部分完后，两个收纳盒对应的RGB灯分别亮起，播放“整理完成！”。
- **知识点落点**：分类就是把有相同特点的东西放一起，让物品变得整整齐齐。

### 第14课 特征放大镜｜特征提取
- **核心知识点**：AI识别物体靠提取关键特征，不是记住整张图
- **点点硬件调用**：彩屏 + 按键 + 放大镜卡纸
- **配套教具**：动物卡片、放大镜造型卡纸
- **动手互动流程**：
  1. 点点屏幕显示一张完整的小动物图片。
  2. 孩子把纸质放大镜放在屏幕上，按A键触发“特征提取”。
  3. 画面切换，只圈出动物的耳朵、尾巴、花纹等关键特征，其他地方变暗。
  4. 更换不同动物，对比特征差异，理解AI靠特点认东西。
- **知识点落点**：AI认东西不是看全貌，而是抓住最特别的几个关键特点。

## 第五模块：概率与预测（第15-16课）
### 第15课 猜一猜明天带伞吗｜概率预测
- **核心知识点**：根据过去的数据，可以预测未来发生的可能性
- **点点硬件调用**：内置随机程序 + 彩屏 + 按键
- **配套教具**：天气骰子、晴雨记录表格、小伞贴纸
- **动手互动流程**：
  1. 孩子投掷天气骰子10次，每投一次在点点上按对应按键记录结果。
  2. 10次记录完成后，点点自动统计下雨次数，屏幕显示柱状图和下雨概率。
  3. 孩子根据概率判断明天是否带伞，在记录卡上贴小伞贴纸。
  4. 再投掷10次，观察概率变化，理解“数据越多，预测越准”。
- **知识点落点**：概率就是一件事发生的可能性大小，过去的数据能帮我们预测未来。

### 第16课 背答案的鹦鹉｜死记硬背的局限
- **核心知识点**：只会背答案不会变通，遇到新问题就无能为力
- **点点硬件调用**：彩屏 + 按键 + 扬声器
- **配套教具**：鹦鹉卡片、已知问题卡、未知问题卡
- **动手互动流程**：
  1. 孩子拿出3张已知问题卡提问，点点都能准确回答，像鹦鹉背答案。
  2. 再拿出从未见过的未知问题卡提问，点点屏幕显示“我不知道”，播放困惑音效。
  3. 对比两种结果，理解只会死记硬背的AI不够聪明。
- **知识点落点**：真正厉害的AI要能举一反三，而不是只会背现成的答案。

## 第六模块：机器学习基础（第17-20课）
### 第17课 学校里的AI同学｜模仿学习
- **核心知识点**：AI可以通过模仿多个例子，学会新本领
- **点点硬件调用**：光线传感器 + 彩屏 + 扬声器
- **配套教具**：圆形、方形卡片各3张、纸质学习卡槽
- **动手互动流程**：
  1. **训练阶段**：孩子连续把3张圆形卡片插进卡槽，每插一张点点说“这是圆形”。
  2. **测试阶段**：插入一张新的圆形卡片，点点自动识别“我学会啦，这是圆形！”。
  3. 用方形卡片重复训练，体验AI通过例子模仿学习的完整过程。
- **知识点落点**：AI就像小朋友，多看几个正确的例子，就能学会新知识。

### 第18课 小狗学握手｜强化学习（试错+奖励）
- **核心知识点**：做错纠正、做对奖励，反复练习就会越来越厉害
- **点点硬件调用**：按键 + 彩屏 + RGB灯
- **配套教具**：小狗卡片、骨头贴纸、动作卡片
- **动手互动流程**：
  1. 孩子按A/B键代表让小狗做不同动作。
  2. 做错了点点亮红灯，播放“不对哦”；做对了（握手动作）亮绿灯，出现骨头奖励。
  3. 反复尝试几次后，孩子能精准按对按键，模拟小狗通过试错学会技能。
- **知识点落点**：每一次错误都是宝贵经验，多练习、多奖励，就会越来越棒。

### 第19课 贴标签的老师｜监督学习
- **核心知识点**：给数据打上正确标签，AI就能跟着标签学习
- **点点硬件调用**：光线传感器 + 彩屏 + 按键
- **配套教具**：水果/动物图片卡、对应类别标签卡、纸质标注卡槽
- **动手互动流程**：
  1. **训练阶段**：孩子把图片卡和标签卡叠在一起插进卡槽，告诉点点“这是苹果，属于水果”。
  2. 给5张图片都贴好标签，完成“监督训练”。
  3. **测试阶段**：只插入图片卡不点标签，点点自动说出它的类别；识别正确表扬，错误就重新贴标签纠正。
- **知识点落点**：监督学习就像老师改作业，告诉AI正确答案，它就会越学越准。

### 第20课 没有标签的玩具箱｜无监督聚类
- **核心知识点**：没有正确答案，AI也能自己按相似性分组
- **点点硬件调用**：光线传感器 + 彩屏 + 按键
- **配套教具**：6张无标签物品卡（3个圆形、3个方形）、纸质玩具箱
- **动手互动流程**：
  1. 孩子把所有无标签卡片依次插进玩具箱卡槽。
  2. 点点自动按照形状特征，把卡片分成两组，屏幕用不同颜色框标注。
  3. 孩子观察结果，发现一组全是圆形、一组全是方形。
  4. 更换不同特征的卡片，观察AI的分组逻辑。
- **知识点落点**：没有老师教，AI也能自己找到规律，把相似的东西归为一类。

## 第七模块：神经网络（第21-24课）
### 第21课 点亮聪明灯｜神经网络分层传递
- **核心知识点**：神经网络分多层，信号一层一层传递，最后得出结果
- **点点硬件调用**：5颗RGB灯 + 彩屏 + 按键
- **配套教具**：神经网络分层卡纸（输入层、隐藏层、输出层）
- **动手互动流程**：
  1. 把分层卡纸摆在点点前方，对应5颗RGB灯：2颗输入层、2颗隐藏层、1颗输出层。
  2. 孩子按下输入按键，输入层2颗灯先亮起。
  3. 接着隐藏层2颗灯接力亮起，最后输出层1颗灯点亮，屏幕同步播放信号传递动画。
  4. 更换不同输入，得到不同输出结果，理解分层思考逻辑。
- **知识点落点**：AI的神经网络就像大脑，信号一层一层传下去，慢慢思考出答案。

### 第22课 从边边角角到整张脸｜逐层特征提取
- **核心知识点**：神经网络从简单线条开始，慢慢拼成完整图案
- **点点硬件调用**：彩屏 + 按键 + 扬声器
- **配套教具**：五官贴纸、人脸轮廓卡纸
- **动手互动流程**：
  1. 孩子先贴线条贴纸在轮廓卡上，按A键，点点屏幕显示“识别到边缘线条”。
  2. 再贴上眼睛、嘴巴贴纸，按B键，屏幕显示“识别到五官特征”。
  3. 全部贴完触发识别，屏幕显示完整人脸，播放“认出来啦！”。
  4. 体验从边缘→五官→整张脸的逐层识别过程。
- **知识点落点**：AI认脸不是一眼看完，而是从线条到细节，一步一步拼出来的。

### 第23课 音量旋钮决定谁更重要｜权重参数
- **核心知识点**：权重就是重要程度，权重越高，对结果影响越大
- **点点硬件调用**：三轴陀螺仪 + 彩屏 + 磁吸底座
- **配套教具**：纸质天平支架、塑料配重块
- **动手互动流程**：
  1. 把点点磁吸在天平的一端，另一端初始为空。
  2. 孩子在另一端逐个添加配重块，天平逐渐倾斜。
  3. 点点通过陀螺仪检测倾斜角度，屏幕实时显示“当前权重比 1:3”，倾斜越厉害权重差越大。
  4. 调整配重块让天平平衡，理解“权重相等，重要程度一样”。
- **知识点落点**：权重就像天平砝码，哪边更重，哪边对结果的影响就越大。

### 第24课 慢慢调准的小箭头｜梯度下降
- **核心知识点**：一点点修正方向，慢慢靠近正确答案，就是梯度下降
- **点点硬件调用**：陀螺仪 + 彩屏
- **配套教具**：纸质斜坡滑轨、目标终点贴纸
- **动手互动流程**：
  1. 把滑轨平放桌面，终点位置贴上目标贴纸。
  2. 孩子把点点放在滑轨顶端松手，让它自然下滑。
  3. 点点通过陀螺仪计算滑行距离，屏幕显示“离目标还差2格”。
  4. 孩子调整滑轨坡度，反复尝试，直到点点刚好滑到目标位置，体验逐步修正逼近答案的过程。
- **知识点落点**：AI学习就像找目标，一次次调整方向，最后就能精准到达。

## 第八模块：NLP与生成式AI（第25-28课）
### 第25课 会接话的鹦鹉2.0｜语言模型序列预测
- **核心知识点**：AI能根据前面的文字，猜出后面该说什么
- **点点硬件调用**：WiFi + 麦克风 + 扬声器 + 彩屏
- **配套教具**：对话开头卡片
- **动手互动流程**：
  1. 点点连接WiFi，接入云端大模型。
  2. 孩子拿起对话开头卡片，对着麦克风读出句子开头，比如“今天天气真…”。
  3. 点点自动补全句子，用语音播报出来，屏幕同步显示文字。
  4. 更换不同开头，体验AI接话接龙的能力。
- **知识点落点**：语言模型就像玩词语接龙，根据前面的内容，猜出后面该说什么。

### 第26课 给AI的清楚指令｜提示词工程
- **核心知识点**：指令说得越清楚，AI给出的答案就越准确
- **点点硬件调用**：WiFi + 麦克风 + 扬声器 + 彩屏
- **配套教具**：模糊指令卡、清晰指令卡各2张
- **动手互动流程**：
  1. 先读模糊指令：“给我讲个故事”，点点输出一个普通短故事。
  2. 再读清晰指令：“给我讲一个团团和点点去火星探险的3句话小故事”。
  3. 对比两次回答，发现指令越具体，故事越符合预期。
  4. 孩子自己创编清晰指令，测试AI的回答效果。
- **知识点落点**：和AI沟通要说清楚要求，它才能给出你真正想要的答案。

### 第27课 从乱点点到清图画｜文生图原理
- **核心知识点**：AI能根据文字描述，生成对应的全新图片
- **点点硬件调用**：WiFi + 彩屏 + 扬声器
- **配套教具**：场景描述卡片（如“蓝色大海上的白色小船”）
- **动手互动流程**：
  1. 孩子选出一张描述卡片，对着点点读出文字内容。
  2. 点点通过WiFi调用文生图接口，生成对应简笔画。
  3. 几秒后，生成的图片显示在点点屏幕上，播放“画好啦！”音效。
  4. 更换不同描述卡片，对比生成的不同画面。
- **知识点落点**：AI能听懂文字描述，然后画出从来没有过的新图画。

### 第28课 会编故事的机器人｜生成式AI
- **核心知识点**：AI可以自主创作全新的故事和内容
- **点点硬件调用**：WiFi + 扬声器 + 彩屏
- **配套教具**：故事元素卡（人物、地点、事件）
- **动手互动流程**：
  1. 孩子随机抽出3张元素卡，比如“团团、森林、寻宝”。
  2. 对着点点说出三个元素，要求它编一个完整故事。
  3. 点点语音播报原创故事，屏幕同步播放对应画面。
  4. 更换元素组合，生成完全不同的新故事。
- **知识点落点**：生成式AI不止会背答案，还能创造出全新的内容。

## 第九模块：AI伦理与未来（第29-32课）
### 第29课 不要随便给陌生人｜隐私保护
- **核心知识点**：个人隐私信息不能随便告诉陌生人和AI
- **点点硬件调用**：按键 + RGB灯 + 彩屏
- **配套教具**：信息卡片（姓名、照片、爱好、学校）、安全/危险收纳盒
- **动手互动流程**：
  1. 孩子抽出一张信息卡，判断能不能告诉陌生人。
  2. 认为可以按A键，不可以按B键。
  3. 答对亮绿灯，播放“保护成功”；答错亮红灯，讲解该信息为什么是隐私。
  4. 把卡片放进对应的安全/危险收纳盒。
- **知识点落点**：姓名、住址、照片都是隐私，要好好保护，不能随便告诉别人。

### 第30课 同样努力却分数不同｜算法公平性
- **核心知识点**：训练数据不公平，AI就会做出不公平的判断
- **点点硬件调用**：彩屏 + 按键 + 扬声器
- **配套教具**：两组小动物练习卡、分数对比卡
- **动手互动流程**：
  1. 点点展示第一组数据：小猫和小狗都做了10次练习，但小猫得100分，小狗得60分。
  2. 再展示第二组真相：小猫的练习题全是见过的，小狗的全是新题。
  3. 孩子按下“公平/不公平”按键，表达判断。
  4. 点点讲解：训练数据不一样，结果就不公平，AI也是同样的道理。
- **知识点落点**：要让AI公平公正，首先要给它公平、全面的学习数据。

### 第31课 超级搭档｜人机协作
- **核心知识点**：人类和AI各有长处，互相配合能做得更好
- **点点硬件调用**：按键 + 彩屏 + WiFi
- **配套教具**：任务分工卡（人类做创意、AI做计算）
- **动手互动流程**：
  1. 给出任务：设计一场生日派对。
  2. 孩子负责想创意主题和游戏，说给点点听。
  3. 点点负责计算需要多少气球、多少蛋糕，列出物品清单。
  4. 共同完成完整方案，理解“人类出创意、AI干杂活”的搭档模式。
- **知识点落点**：AI是人类的好帮手，大家各司其职，就能完成更厉害的事。

### 第32课 小小AI研究员毕业啦｜学习进化论
- **核心知识点**：学习是积累的过程，毕业是新探索的开始
- **点点硬件调用**：全彩灯效 + 扬声器 + 彩屏 + WiFi
- **配套教具**：纸质博士帽、荣誉证书模板、32课知识点贴纸
- **动手互动流程**：
  1. 孩子戴上纸质博士帽，按下毕业确认键。
  2. 点点播放毕业音乐，5颗RGB灯跑马灯闪烁，上演毕业灯光秀。
  3. 屏幕滚动播放32课知识点跑马灯回顾，最后弹出电子荣誉证书。
  4. 孩子把知识点贴纸贴在实体证书上，点点语音祝贺毕业，同时提示“还有更多知识等着探索”。
- **知识点落点**：毕业不是终点，保持好奇心，我们永远都在学习新本领的路上。
