# CyberPi 官方参考素材

本目录只存放从 Makeblock 官方帮助中心导出的硬件参考图，用于页面展示与美术校对。

- `cyberpi-electronic-map.png`：童芯派主控板电子特性图，来源：<https://www.yuque.com/makeblock-help-center-zh/cyberpi/electronic_characteristics>
- 图中结构以官方页面为准：摇杆、A/B 键、HOME 键、Type-C、彩屏、麦克风、光线传感器、RGB 灯带、扬声器等。

课程插画不得让生成模型自由改画 CyberPi；若画面需要出现硬件，应优先直接使用官方产品素材或经过授权的实拍图进行合成。
